Forgia Note Epsilon

Scegli il tipo, compila i campi e incolla il testo dal manuale. La nota esce nel formato del vault, con il percorso giusto.

Incolla tutto

Una pagina alla volta: classe, sottoclasse, talento, background, incantesimo o specie.

Collegamenti automatici

Le parole che corrispondono a note del vault diventano link Obsidian, ad esempio «Charmed» → [[Charmed-Affascinato|Charmed]]. Anche le note che crei qui entrano nell'elenco, così le classi successive si collegano a quelle già fatte.

Cosa collegare
Parole ambigue, es. «Light» (proprietà, ma anche «Light Armor»).
Una riga per collegamento: parola = Nome della nota.
Aggiorna l'elenco delle note
Il browser legge solo i nomi dei file .md, non il contenuto. Fallo quando aggiungi note nuove al vault.
